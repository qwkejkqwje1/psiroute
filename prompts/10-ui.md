# Шаг 10 — Tauri 2 GUI + трей

Стек: Tauri 2 (`tray-icon` feature), плагины `autostart`, `single-instance`, `window-state`; фронт Svelte 5 + Vite + TypeScript, без UI-фреймворков (свой CSS, ~всё в одном бандле < 300 КБ). Движок — in-process (`psi-engine`), события → `app.emit("engine", ev)`, команды → `#[tauri::command]`.

## Дизайн
Тёмная тема, glassmorphism, акцент #7C5CFF→#00D1FF градиент, скругления 16px, шрифт Inter/системный, плавные анимации 150–250 мс. Окно 380×640, без рамки (кастомный titlebar), закрытие = скрыть в трей.

## Экраны
1. **Главный**: большая круглая кнопка «Подключить» с анимированным кольцом состояния (серый/жёлтый-пульс/зелёный); под ней: страна (флаг-эмодзи из ISO + название по-русски) → открывает пикер; стратегия («напрямую / DPI / Worker / WARP»), скорость ↑↓ живым графиком-спарклайном, пинг.
2. **Пикер стран**: поиск, «Лучшая (авто)», избранное (звёздочка), пинг-бейджи; выбор = `SetRegion`.
3. **Маршруты**: переключатель пресета карточками (Умный РФ / Только заблокированное / Всё через VPN / Свои); список правил «Что → Куда» с иконками действий, drag-n-drop, добавление «Сайт / Приложение (выбор .exe) / Страна IP»; тестер «Куда пойдёт: [домен]» с объяснением правила.
4. **Подключения (live)**: лента последних 200 соединений (домен, процесс, действие, цвет); клик → «всегда через VPN / напрямую / блок» (создаёт правило). Главная фича простоты.
5. **Настройки**: импорт `vless://` (вставка/QR не нужен), сканер чистых IP CF, WARP (зарегистрировать / импорт .conf / сканер), DPI (автоподбор), TUN-режим (предупредить о правах администратора → перезапуск с UAC `runas`), системный прокси, автозапуск, язык RU/EN, kill-switch.
## Трей
Иконка по состоянию (3 PNG), ЛКМ — показать окно, ПКМ-меню: Подключить/Отключить; Страна ▸ (Лучшая + избранные + 10 последних); Режим ▸ (пресеты); TUN ☐; Открыть; Выход.
## Проверка
`cargo check -p app`; `npm run build` фронта.
