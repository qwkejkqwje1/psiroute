# Шаг 11 — CI, релизы, данные

`.github/workflows/release.yml` (на тег `v*` и вручную), матрица windows-latest / ubuntu-22.04 / macos-14:
1. Go 1.22+: `git clone --depth 1 https://github.com/Psiphon-Labs/psiphon-tunnel-core && cd psiphon-tunnel-core/ConsoleClient && go build -trimpath -ldflags "-s -w" -o <out>` → `app/src-tauri/binaries/psiphon-tunnel-core-<target-triple>[.exe]` (Tauri `externalBin`).
2. Windows: скачать wintun (https://www.wintun.net/builds/wintun-0.14.1.zip), положить `wintun.dll` (amd64) в resources.
3. Скачать `geosite.dat`/`geoip.dat` из `runetfreedom/russia-v2ray-rules-dat` releases/latest в resources (стартовые списки; дальше — автообновление).
4. `tauri-apps/tauri-action`: NSIS (Windows), AppImage+deb, dmg. Артефакты + черновик релиза.
5. `ci.yml` на push: только `cargo check --workspace` + `cargo clippy` (быстро, кэш `Swatinem/rust-cache`).
