# PsiRoute Go 2.4.0 — пакет исходников для разработки

- **Программа:** PsiRoute, **Go-линия** (один пакет `main`, GUI на Gio + веб-панель).
  НЕ путать с Rust-линиями: PsiRoute Slint (панель 9090, другой репозиторий) и psiroute-rs (панель 9091).
- **Версия:** 2.4.0 (`const version` в main.go). Номер выпуска для манифеста обновлений: `currentRelease = 20400` (updater.go; схема major*10000 + minor*100 + patch, поднимать с каждой версией).
- **Панель:** http://127.0.0.1:9090 · **Прокси:** SOCKS5+HTTP 127.0.0.1:1080.
- **База:** дерево 2.3.9-complete (оркестратор, шаги 2–7) + правки Rocky по подключению
  (ROCKY-FIXES.md; поведенческие НЕ откатывать: `newPhysUDPBind()` в warptun.go, порядок стратегий
  с via-warp первой, нет правила «direct/desync всегда раньше WARP» в buildRoundZeroPlan)
  + правки по аудиту (ниже).
- **Сборка на Windows:** `build.bat`, тесты: `test.bat` (нужен Go 1.26.x).

## Что сделано по аудиту в 2.4.0
- A-06: `safeGo`/`safeLoop` (safe.go) — все фоновые запуски; цикл перезапускается с backoff, после 5 падений за минуту компонент failed.
- A-04/A-03: зеркало сидов с Timeout 15 с и редиректом только https на тот же хост; записи только с публичными адресами; лимит 500 записей за импорт;
  честные статусы сидов (ok / reachable / failed / unchecked); предупреждение о доверии при первом импорте из нового источника.
- A-02/A-09: «ограничение ~16 КБ» — только при обрыве в окне 12–24 КБ на ДВУХ адресатах; «DNS отравлен» — минимум по двум хостам.
- A-10: `saveOrReport`/`saveOrFail`; провал записи настроек даёт 500 с понятным текстом, UI не показывает «сохранено».
- A-12: таймауты у всех `http.Client`.
- A-05: автозапуск — один механизм; задача RL HIGHEST только если папка exe не доступна на запись обычным пользователям (проверка по SID).
- A-16: `panic` → `error` в warpi1.go.
- A-07: манифест обновления v2 `"v2|release|version|sha256|url|not_after"`; v1, release <= текущего и просроченные отвергаются.
  Ключ `defaultBootstrapEd25519PubHex` (dns.go) ПУСТОЙ — проверка отказывает; для включения обновлений нужен настоящий публичный ключ разработчика.
- A-17: предупреждение о повреждённом конфиге не сбрасывается при сохранении; сбрасывается `POST /api/config/ack-corrupt`.
- Мелочи: `-pprof` только loopback; `openBrowser` только http/https; SOAK-отчёт подписан как симуляция (A-18).
