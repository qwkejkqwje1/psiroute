# PsiRoute 1.2.1 — исправления версии 1.2.0 (Gio)

Сборка: `go vet ./... && go test ./... && go build -ldflags "-H windowsgui -s -w" -o psiroute.exe`
В песочнице аудита не было Go, поэтому код НЕ собирался и тесты НЕ запускались. Полный diff — `fix-1.2.1.patch`.

## Память (главная причина роста RAM)
- `gui_gio.go`: каждый запрос окна к ядру создавал новый `http.Client` + `http.Transport`. У такого транспорта keep-alive соединение висит вечно (`IdleConnTimeout = 0`), поэтому каждый опрос (раз в 1,2 с) оставлял TCP-соединение, 2 горутины и буферы в окне и ещё горутину в ядре. За несколько часов — тысячи соединений. Теперь один общий клиент: 2 соединения максимум, простаивающие закрываются через 30 с.
- `/api/apps` (снимок всех процессов Windows) и `/api/rules` (сериализация всего конфига) запрашивались каждые 4,8 с даже на других вкладках. Теперь — только для открытой вкладки и один раз при старте.
- Свёрнутое окно: опрос раз в ~10 с и без перерисовки.

## Ошибки
- `apps.go` `appsView()`: `appCurrentRoute()` вызывался под `cfg.mu`. Мьютекс нереентерабельный, поэтому ядро и интерфейс зависали, как только появлялось хотя бы одно правило для программы. В присланных исходниках этой правки не было, хотя README пишет, что она сделана.
- `apps.go` `SetAppRoute()`: при смене маршрута программы удалялись и исключения вида `!app.exe` из чужих правил. Теперь исключения сохраняются.
- `lists.go`:
  - `DOMAIN,x.com` и `full:x.com` работали как «домен и все поддомены». Теперь это точное совпадение.
  - `DOMAIN-KEYWORD`, `keyword:` и sing-box `domain_keyword` молча выбрасывались. Теперь работают (ключ от 3 символов, не больше 4096 ключей).
  - `regexp:` превращался в мусорный «домен». Теперь пропускается.
  - sing-box `domain` теперь тоже точное совпадение.
  - Атрибуты v2fly (`domain:x.com @cn`) отрезаются.
- `v110_test.go` не компилировался, и из-за этого не собирались вообще все тесты пакета. В нём вызывались несуществующие `parseList(string)`, `appRouteMap`, `newI1Wrap`, `warpMaskLabel`, `newObfsBook/record/orderFor/flush`, у `parseECHFromDNS` была неверная сигнатура, и висел лишний импорт `context`. Тест списков переписан на настоящий API с проверкой точных доменов, ключевых слов и regexp. Тесты MASQUE и obfsBook удалены, потому что этих функций в коде нет.
- `main.go`: версия `1.1.0-dev` заменена на `1.2.1`.

## Новое
- «Программы»: кнопка «Страна» у каждой программы. Каждое нажатие переключает выход по кругу: DE → NL → … → SG → обычный VPN. Можно отправить, например, Discord через Германию, а браузер через Нидерланды.

## Не изменено (осознанно)
- Блокировка STUN оставлена только для прямых соединений. Через туннель STUN не раскрывает реальный IP, а полная блокировка ломает звонки Discord и Telegram.
