# PsiRoute 1.3.0 — обновление дизайна (на базе 1.2.1)

Код не собирался в среде разработки (нет Go). Перед выпуском:

```
go vet ./... && go test ./... && go build -ldflags "-H windowsgui -s -w" -o psiroute.exe
```

## Почему продолжаем 1.2.x, а не начинаем с 1.1
- Интерфейс на Gio — правильный путь: он лёгкий. Большой расход памяти давал не Gio, а утечка подключений (исправлена в 1.2.1).
- Ядро 1.2 (маршрутизация программ, страны, списки, DPI, WARP) новее и полнее, чем в 1.1. Откат потерял бы эти функции.

## Дизайн
- **Векторные иконки** (gui_icons.go): 17 иконок рисуются примитивами Gio, без шрифтов и файлов. Заменяют эмодзи и символы, которые встроенный шрифт Go не умеет рисовать и показывал квадратиками (⚡ 🧩 🔀 🛡 📡 ⚙ ☀ 🌙 🌐 📦 ↻ ⇄ ✓ ▶).
- **Боковое меню**: иконка + текст, у активного пункта — акцентная полоска слева, курсор-«рука» при наведении.
- **Новая палитра**: тёмная — глубокий графит с мягким индиго-акцентом; светлая — чище и контрастнее. Мягкие заливки, тонкие границы, радиус карточек 14.
- **Кнопки**: единый компонент с иконкой; активная кнопка окрашивается цветом своего режима (зелёный «Напрямую», красный «Блок», фиолетовый «VPN», бирюзовый «DPI»), поэтому маршрут программы виден сразу. Наведение работает для всех стилей.
- **Вкладка «Программы»**: короткий заголовок и описание, компактные переключатели «Запущенные · N / Каталог · N», **поиск** по имени exe, названию и категории, сообщение «Ничего не найдено».
- Тексты кнопок сокращены, версия в меню без технических подписей.

## Изменённые файлы
- gui_icons.go — новый.
- gui_gio.go — палитра, кнопки, меню, поиск, замена символов.
- main.go — версия 1.3.0.
