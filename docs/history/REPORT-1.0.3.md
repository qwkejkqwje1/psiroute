# Psiroute 1.0.3 — аудит и прогон тестов (Muse, 08.11.2026)

## Вердикт

1.0.3 собирается (Linux и Windows), `go vet` чист, staticcheck — только прежние
3× ST1005 (русские строки ошибок с заглавной — осознанно оставлены).
Все тесты зелёные: **59 шт., 58 pass + 1 skip** (LAN-сценарий недостижим в
песочнице), `go test -race` чист, покрытие **69,9%**.

## Что сделано строителем в 1.0.1–1.0.3 (проверено по коду и тестами)

- Fallback портов: UI 9091–9110 → любой свободный; прокси — следующие 20
  (порт раздачи пропускается). Живая проверка в песочнице: при занятых
  19090/11080 программа подняла интерфейс на 19091 и прокси на 11081.
- `psiroute.instance` с фактическим адресом; повторный запуск открывает окно
  работающей копии. Ошибка запуска — окном сообщения (windowsgui).
- Сброс «висячего» системного прокси при старте.
- F1/F2/F4 из отчёта по 1.0.0 приняты (ptr(true), base64 RSL, errTimeout);
  go.mod честно поднят до Go 1.26. go.sum в архив не вложен — нужен
  `go mod tidy` перед первой сборкой (сделан, go.sum приложен к пакету).
- Маршрутизация: learned только в режиме auto; TTL 14 дней; лимит 2000,
  вытеснение самого старого; hits растут при использовании; сохранение
  атомарно, с дебаунсом 2 с и flush при выходе; forget удаляет и поддомены.
- Правила: домены/ключевые слова/CIDR — ИЛИ, порты — И с ними; ключевое слово
  без учёта регистра; CIDR кэшируется, голый IP = /32.
- API без токена — 403 (как в ТЗ). /api/rules отдаёт outbounds,
  /api/route отдаёт port, chain, learned. Токен — constant-time, тело ≤ 1 МБ.
- Прокси: HTTP keep-alive фикс (одно соединение — один запрос), перебор до
  3 IP, обучение DPI только по RST/закрытию сервера, https-апстрим через TLS.

## Правки Muse поверх 1.0.3

- **F5 (косметика)**: удалены мёртвые `App.directAddr` и `isAddrInUse`
  (staticcheck U1000) — остатки после переписывания app.go/proxy.go.
- **F6 (функциональная)**: POST /api/rules принимал и сохранял правила с
  пустым outbound — ровно тот класс бага, от которого 1.0.3 чинил UI.
  Теперь: 400 «у правила не указан маршрут», сохранение целиком отклоняется.
