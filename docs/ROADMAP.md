# Roadmap (отмечать [x] после шага)

- [x] 00 Промпт-план, архитектура, репозиторий
- [x] 01 Workspace-скелет + psi-config + psi-core (трейты, SOCKS5/HTTP inbound, DIRECT outbound)
  - Сделано: workspace (psi-config, psi-core), загрузка/сохранение TOML с deep-merge и выносом секретов в `config.local.toml`, `Target/Outbound/BoxStream/Event/EventBus`, `DirectOutbound`, `MixedInbound` (SOCKS5 + HTTP CONNECT/proxy) со счётчиками `Event::Stats`.
  - Тесты: парсинг SOCKS5 (IPv4/домен), merge конфигов, разделение секретов, подсчёт событий, DIRECT-connect. `cargo check`, `clippy -D warnings`, `cargo test` зелёные.
  - Осталось: реальный append фактического трафика в UI появится вместе с движком (шаг 09).
- [x] 02 psi-psiphon: сайдкар, config.json, notices, страны
  - Сделано: `PsiphonConfig` (PascalCase config.json), `PsiphonInstance` (spawn/kill_on_drop/CREATE_NO_WINDOW), парсинг notices в `watch`-состояние и `Event`-шину, `wait_connected`, `stop`, `restart_with_region`, `PsiphonOutbound` через SOCKS5, список стран по умолчанию.
  - Прямой режим: `upstream_proxy_url = None` — Psiphon сам обходит блокировки своими протоколами (OSSH/TLS-OSSH/meek/QUIC), без VLESS/WARP/DPI-хопов.
  - В psi-core добавлен переиспользуемый SOCKS5-клиент (`socks5_connect`).
  - Осталось: реальная сборка/поставка бинаря `psiphon-tunnel-core` — шаг 11 (CI).
- [x] 03 psi-vless: VLESS-WS-TLS клиент + early-data; модернизация Worker
  - Сделано: VLESS-заголовки (IPv4/домен/IPv6), ответный парсер, TLS (rustls + webpki-roots, ALPN h1), WS-upgrade с проверкой эха subprotocol, early-data ≤50 мс в `Sec-WebSocket-Protocol`, `VlessOutbound`, `vless://` парсер, `serve_socks`, `scan_clean_ips` (32 параллельно, топ-5), тест «16КБ-заморозки».
  - Worker: эхо subprotocol, несколько UUID в постоянном времени, `PROXYIP` fallback, UDP DNS→DoH, `/api/v1/dns`, прикрытие с кэшем, `wrangler.toml` и README.
  - Осталось: реальную DPI-фрагментацию ClientHello подключить на шаге 04 (хук `fragment` уже есть).
- [x] 04 psi-dpi: DPI-мост (TLS split/фрагментация), DoH
  - Сделано: `DpiOutbound` (перехват первой записи, nodelay, duplex), парсер ClientHello/SNI и HTTP `Host`, стратегии `split/tlsrec/disorder/oob/httphost` + 4 пресета, `autotune` по 4 хостам (≤4 параллельно), DoH (`hickory-proto` + `h2` поверх `DpiOutbound`, гонка серверов, кэш), `serve_socks`, опциональный запуск внешних движков.
  - Тесты: SNI/offset, две валидные TLS-записи (склейка = исходник), HTTP Host и переписывание без смены длины, парсер стратегий, DPI-bridge, DoH bootstrap/запрос.
- [ ] 05 psi-warp: WARP + boringtun + AWG-junk + сканер эндпоинтов
- [ ] 06 psi-bootstrap: гонка стратегий + кэш
- [ ] 07 psi-router: правила, geoip/geosite, пресеты
- [ ] 08 psi-tun: TUN-режим, fake-ip DNS, защита от петель
- [ ] 09 psi-engine: сборка движка, команды, CLI
- [ ] 10 app: Tauri 2 UI + трей + выбор стран
- [ ] 11 CI/релизы: сборка psiphon, wintun, установщики, автообновление списков
