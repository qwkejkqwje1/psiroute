# Правила для ИИ-исполнителя (читать ВСЕГДА перед шагом)

1. Делай ТОЛЬКО текущий шаг из `prompts/NN-*.md`. Не трогай чужие крейты без причины.
2. Язык: Rust stable (edition 2021), async = tokio. Ошибки: `thiserror` в библиотеках, `anyhow` в бинарях. Логи: `tracing`.
3. Никаких `unwrap()`/`expect()` в рабочем коде (только в тестах). Никаких `unsafe` без комментария `// SAFETY:`.
4. Проверка минимальная: `cargo check --workspace` + `cargo clippy -p <крейт> -- -D warnings` + тесты, указанные в шаге. Больше не нужно.
5. Секреты (UUID, токены, ключи WARP) — НИКОГДА в git. Только `config.local.toml` (в .gitignore) или переменные окружения.
6. Публичные API крейтов — как в `docs/ARCHITECTURE.md`. Если меняешь контракт — обнови документ в том же коммите.
7. В конце шага:
   - отметь шаг `[x]` в `docs/ROADMAP.md`, допиши 1–3 строки «что сделано / что осталось»;
   - бэкап: `git add -A && git commit -m "step NN: <кратко>" && git push` (токен берётся из `GITHUB_TOKEN`, не вписывать в файлы).
8. Если шаг слишком большой для контекста — раздели на NNa/NNb, закоммить NNa и остановись.
