Обход блокировок для Psiphon

DPI-обход (как в zapret)дробление TLS/TCP, чтобы провайдер не распознал подключение к Psiphon
Метод DPI-обхода«Авто» запоминает рабочий метод для каждого сайта, а при сбросе или молчании сам повторяет подключение другим — без обрыва загрузки
Как работают методы—
Cloudflare WARP как подложкаспособ «Через WARP»: Psiphon подключается изнутри WARP, провайдер видит только WireGuard к Cloudflare. Встроенный WARP включается, только когда нужен
Маскировка WARPчем притворяется начало соединения; «Авто» перебирает и запоминает рабочую
Какой WARPвстроенному не нужны другие программы; внешний — SOCKS5 другой программы (адрес ниже)
Адрес внешнего WARPтолько для «внешний SOCKS5», например 127.0.0.1:18181
Состояние WARP—
Шифрованный DNSпровайдер не подменит адреса
Бесшовное переключение маршрутовесли маршрут не открыл сайт — сразу пробовать следующий
Запоминать рабочие маршрутыдля сайтов, которые открылись не с первого раза
UDP через проксидля программ, которые сами шлют UDP в SOCKS5: звонки Telegram, игры через Proxifier. Браузеры и Discord так не умеют
Режим TUNвесь трафик компьютера через Psiroute: игры, голос Discord, лаунчеры. Нужны права администратора; драйвер Wintun скачается сам
Состояние TUN—
TUN: исключенияпрограммы всегда напрямую, через запятую (например bank.exe)
FakeIP для режима TUN (198.18.0.0/15)мгновенное сопоставление 100% TCP/UDP-пакетов с точным доменом даже без SNI (игры, STUN/TURN)
Локальный DNS-сервер (127.0.0.1:5353)системный UDP DNS-резолвер через защищённый DoH с поддержкой FakeIP и ECH

ищу браузеры…
Firefox: Настройки → Основные → Параметры сети → «Настроить…» → «Ручная настройка прокси». В «Узел SOCKS» — сервер, в «Порт» — порт, выберите SOCKS 5 и отметьте «Проксировать DNS-запросы при использовании SOCKS v5». Или выберите «URL автоматической настройки прокси» и вставьте адрес PAC.
Chrome, Edge, Яндекс, Opera: берут системный прокси — включите его на главной. Если прокси нужен только в браузере — кнопка выше или расширение ZeroOmega / Proxy SwitchyOmega: протокол SOCKS5, сервер и порт отсюда.
Проверка: откройте любой сайт «мой IP» — должен показаться адрес не вашего провайдера. Если Psiroute выключен, браузер с ручным прокси не откроет сайты: это защита от утечки, а не поломка.
