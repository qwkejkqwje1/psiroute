# PsiRoute

Лёгкий быстрый клиент на Rust: **Psiphon + умная маршрутизация + обход DPI/блокировок в РФ** (WARP/AmneziaWG-обфускация, свой VLESS-WS-прокси на Cloudflare Worker, фрагментация TLS). GUI в трее (Tauri 2), выбор стран.

- Архитектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- План и статус: [docs/ROADMAP.md](docs/ROADMAP.md)
- Правила для ИИ-исполнителей: [AGENTS.md](AGENTS.md)
- Промпты по шагам: [prompts/](prompts/)

Как работать: дайте модели `AGENTS.md` + `docs/ARCHITECTURE.md` + ОДИН файл `prompts/NN-*.md`. После шага — коммит и push.
