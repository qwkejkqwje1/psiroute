# Psiroute 2.0.2 (Go)

Лёгкий десктопный клиент для Windows (и Linux/macOS в консольном/браузерном режиме) для стабильного подключения к сети **Psiphon VPN** в условиях жёстких блокировок ТСПУ: встроенный движок `psiphon-tunnel-core`, подложка **Cloudflare WARP (WireGuard / MASQUE + ECH)**, локальный **DPI-обход** (как в zapret/GoodbyeDPI), виртуальный сетевой адаптер **TUN (Wintun)**, пул **FakeIP**, умная маршрутизация по доменам, спискам, подсетям и приложениям (**Split Tunneling**), а также аппаратно-ускоренный векторный интерфейс на **Gio UI** (`< 8 МБ ОЗУ`, без процессов `msedgewebview2.exe`).

---

## Ключевые возможности версии 2.0

### 1. Умное подключение к Psiphon и память по сетям
- **Внутрипроцессное ядро `psiphon-tunnel-core`:** прямое управление фрагментатором, разрезом TLS `ClientHello`, выбором протоколов (`FRONTED-MEEK`, `INPROXY-WEBRTC` Conduit, `TLS-OSSH`, `QUIC-OSSH`, `OSSH`, `SHADOWSOCKS`) и прокси-подложкой без промежуточных локальных портов.
- **Память стратегий по сетям (`psiroute-strategies.json`):** программа вычисляет отпечаток текущей сети (подсеть шлюза + имя и MAC сетевого адаптера) и хранит для каждой сети число попыток, успехов, медианное время входа и медианное время жизни туннеля по каждому способу. При переключении между домашним интернетом, офисным Wi-Fi и мобильным хотспотом мгновенно выбирается лучший способ для конкретной сети.
- **Параллельная гонка протоколов в первом раунде:** сначала проверяется лучший способ для текущей сети с коротким окном (`18 с`); если он не ответил — запускается объединённая гонка всех прямых протоколов в одном контроллере (`35 с`), что обеспечивает подъём рабочего туннеля менее чем за **60 секунд**.
- **Сохранение выученных параметров `NetworkID`:** идентификатор сети привязан к реальному сетевому профилю и не сбрасывается при автоматических проверках связи или скорости, сохраняя накопленные `tunnel-core` тактики и рабочие серверы.
- **Мульти-целевая проверка связи и защита живого трафика:** пинг проверяет три независимые цели (`www.gstatic.com`, `cp.cloudflare.com`, `connectivitycheck.gstatic.com`), сверяет наличие прямого интернета и никогда не рвёт туннель, по которому за последние 15 секунд шёл пользовательский трафик.
- **Резервные источники серверов и ручной импорт:** поддержка нескольких `RemoteServerListURLs` с `OnlyAfterAttempts` и импорт записей серверов (`server entries`) из текста/файла.
- **Автоматическая диагностика причин:** классификация сбоев (`нет сети`, `нет серверов-кандидатов`, `таймаут всех кандидатов`, `сброс после рукопожатия DPI`, `не отвечает внешний прокси/WARP`, `рассинхронизация часов`) с понятной подсказкой на главном экране и статистикой в `GET /api/psiphon/stats`.

### 2. Пользовательские и встроенные списки маршрутизации
- **Реестр списков в `psiroute.json` (`lists.custom`, `lists.hidden`, `lists.trusted_hosts`):**
  - Добавление собственных списков по HTTPS-ссылке, вставкой текста (в многострочном редакторе) или импортом из файла.
  - Встроенный каталог из 12 преднастроенных списков (`youtube`, `discord`, `telegram-ip`, `meta-instagram`, `twitter-x`, `ai-services`, `gaming-steam-epic`, `ru-gov-banks`, `ads-trackers`, `ru-blocked`, `antifilter-community`, `antifilter-ip`), которые можно скрывать и восстанавливать одной кнопкой («Вернуть встроенные»).
- **Широкая поддержка форматов и предпросмотр:**
  - Обычные списки доменов и IP/CIDR, файлы `hosts`, правила **Clash** (`DOMAIN-SUFFIX`, `DOMAIN`, `DOMAIN-KEYWORD`, `IP-CIDR`), **sing-box JSON**, списки **v2fly** (`domain:`, `full:`, `keyword:`, рекурсивное раскрытие `include:`, пропуск `regexp:` с предупреждением).
  - Предпросмотр перед сохранением показывает число распознанных доменов, подсетей, отброшенных строк и предупреждений.
- **Безопасность и целостность правил:**
  - Бинарный поиск по IPv4/IPv6 интервалам за $O(\log N)$ и потоковый парсер без скачков памяти.
  - Защита от SSRF и небезопасных редиректов при скачивании списков; запрос подтверждения пользователя для новых HTTPS-хостов.
  - Защита при удалении: если список используется в правилах маршрутизации, программа показывает список этих правил и предлагает безопасно убрать список из правил или отменить удаление.
  - Атомарная запись всех файлов конфигурации и списков (`tmp` + `Sync` + `Rename`), устойчивая к обрыву питания.

### 3. Векторный интерфейс Gio UI и навигация
- **Компактный главный экран (`1100×720` без вертикальной прокрутки):**
  - Слева: кнопка питания, состояние и причина/совет при ошибке, строка из 4 метрик (страна, задержка, скорость, время сессии), кнопка «Сменить сервер» и меню «⋯» (Другой способ, Автоподбор, Тест скорости, Перезапуск).
  - Справа: переключатель режима маршрутизации (`Всё через VPN`, `По правилам`, `Автообход`), выбор страны выхода и 4 главных переключателя (`Системный прокси`, `Режим TUN`, `Cloudflare WARP`, `Kill Switch`).
  - Внизу: живой график скорости на всю ширину и строка «Быстрое правило».
- **7 разделов бокового меню и адаптивность:**
  1. `Главная`
  2. `Правила и списки`
  3. `Программы` (Split Tunneling для запущенных процессов и каталога игр/приложений)
  4. `Страны и обход DPI`
  5. `Подключение устройств` (адреса прокси для браузеров, PAC, раздача в локальную сеть с QR-кодом)
  6. `Диагностика` (тест сайтов с проверкой ECH, статистика способов Psiphon, импорт серверов, обслуживание, активные соединения)
  7. `Настройки` (все переключатели сети, DNS, FakeIP и защиты от утечек + живой журнал)
  - При ширине окна менее `900px` боковая панель сворачивается в иконки, а правая колонка переносится под левую.
- **Горячие клавиши:**
  - `Ctrl+1 … Ctrl+7` — быстрый переход по вкладкам;
  - `Ctrl+Enter` — подключить / отключить Psiphon;
  - `Ctrl+F` — фокус в поле поиска на активной вкладке;
  - `Alt+0 … Alt+6` — переключение метода DPI-обхода в веб-панели.

### 4. Режим TUN, FakeIP, DoH + ECH и обход DPI
- **Режим TUN (`Wintun`):** перехватывает весь TCP/UDP-трафик системы (игры, голосовые каналы Discord, лаунчеры). Поддерживает список исключений приложений (`tun.exclude_apps`) и автоматический запрос прав администратора.
- **Пул FakeIP (`198.18.0.0/15`) и локальный DNS (`127.0.0.1:5353`):** мгновенное сопоставление IP-пакетов с доменными именами даже для протоколов без TLS SNI.
- **Локальный DPI-обход:** 5 методов десинхронизации TLS `ClientHello` и HTTP `Host` с автоматическим обучением и прозрачным повтором при сбросе (RST) или молчании сервера.
- **Cloudflare WARP:** встроенный клиент WireGuard с маскировкой рукопожатия (`QUIC + ECH`, `MASQUE HTTP/3`, `bash-warp-generator`, `DNS`) для запуска Psiphon внутри защищённого канала.

## Сборка и запуск

Требуется **Go 1.26+** (ОС Windows 10/11 для нативного окна Gio, системного прокси и Wintun; Linux/macOS поддерживаются для работы ядра и веб-панели).

```bash
go mod tidy
go vet ./...
go test ./...
go build -ldflags "-H windowsgui -s -w" -o psiroute.exe .
```

### Основные флаги командной строки

```text
--config <path>        Путь к конфигурационному файлу (по умолчанию psiroute.json)
--profile <name>       Выбор активного профиля при запуске
--mode <tun|proxy>     Переопределение режима работы (tun, proxy, rules, psiphon, auto)
--listen <ip:port>     Адрес и порт локального SOCKS5/HTTP прокси (по умолчанию 127.0.0.1:1080)
--web-addr <ip:port>   Адрес встроенного веб-интерфейса (по умолчанию 127.0.0.1:9090)
--headless, --no-gui   Фоновый консольный режим без окна Gio и системного трея
--tray, --minimized    Запуск свёрнутым в системный трей
--autoconnect          Автоматический запуск туннеля сразу при старте
--test-config          Валидация конфига и правил с выводом ошибок (exit 0 / exit 1)
--selftest             Запуск встроенной самопроверки и сохранение psiroute-selftest.txt
--no-watchdog          Запуск без процесса-сторожа
--version              Вывод версии сборки
```

## Файлы данных рядом с программой

- `psiroute.json` — конфигурация, правила и реестр пользовательских списков (`lists.custom`, `lists.hidden`, `lists.trusted_hosts`).
- `psiroute-strategies.json` — статистика и рейтинг способов подключения к Psiphon по каждой сети.
- `lists/` — кэш загруженных списков и файлы локальных пользовательских списков.
- `psiphon/` — локальная база данных серверов и тактик `psiphon-tunnel-core`.
- `psiphon-server-entries.txt` — импортированные пользователем записи серверов Psiphon.
- `psiroute-learned.json` — автоматически выученные маршруты для заблокированных сайтов.
- `psiroute-obfs.json` — кэш лучших методов DPI-обхода по сайтам.
- `psiroute-days.json` — посуточная статистика трафика.
- `warp-identity.json` — ключи встроенного устройства Cloudflare WARP (никогда не включаются в диагностический отчёт).
- `psiroute.log`, `psiroute.log.1`, `crash.log` — журналы работы и аварийных сбоев.

## Честные ограничения (Psiphon в РФ)

- Никакой набор тактик не гарантирует подключение у каждого российского провайдера; задача оркестратора — быстро найти рабочий путь, запомнить его для текущей сети и выдать точную диагностику с действием, если путь недоступен.
- Без достижимого начального списка серверов (загрузка RSL, импорт записей или доверенное пользовательское зеркало) Psiphon не сможет подключиться; при отсутствии записей интерфейс явно показывает `NO_SEED` с действием импорта.
- Ограничение передачи после ~16 КБ на ряде зарубежных диапазонов/CDN сообщается сообществом и зависит от конкретного провайдера; проба `>= 64 КБ` выявляет такой канал, а обход строится за счёт разнообразия носителей (`direct+dpi`, `warp`, пользовательский `worker`, `proxy`).
- Использование общих тестовых идентификаторов (`FFFFFFFFFFFFFFFF`) может ограничивать выдачу региональных тактик серверами Psiphon; для распространения и задач вне личного использования получите официальные значения у Psiphon.
